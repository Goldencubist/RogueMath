# ROGUEMATH
Jogo roguelite estilo survivor.io com tema de matemática


### CONTROLES
- W, A, S, D = Cima, Esquerda, Baixo, Direita
- Clique Esquerdo = Atirar

### Como jogar:
Como ainda está em desenvolvimento e uma beta não foi postada no itch.io, deverá se seguir o seguinte passo a passo:
1. Se certificar de ter onde rodar (interpretador python)
2. Baixar o código fonte em zip
3. Extrair o código fonte
4. Rodar o arquivo RogueMath.py
